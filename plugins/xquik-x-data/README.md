# xquik-x-data

Claude Code skill for planning Xquik API and remote MCP workflows.

## Install

```text
/plugin install xquik-x-data@dotclaude
```

## What It Covers

- X data extraction and search workflows
- Account and keyword monitoring
- Webhook delivery planning
- Remote MCP connection planning
- API request planning from the public OpenAPI document
